# 均匀分赃

[手机打开，来分一局](https://zxzin.github.io/jun-yun-fen-zang/)

蒙眼歪歪来守盒，大家来做主。2–12 人轮流盲填，通过卡片表达自己的期待、猜测队友的期待，最后一起揭晓分配结果。

## 怎么玩

1. 选积分、奖金、时长或自定义资源，设置总量和人数。
2. 约定各自是几号玩家，轮流拿同一台设备。
3. 选择自己想拿的数量，再逐个猜队友。卡片可左右滑动。
4. 选择接受范围，封存盲盒。交接时上一份内容移出可见界面。
5. 所有人完成后一起开盒，查看所得并确认，可导出文字结果。

每位玩家的自身期望与队友猜测先按比例换算成一份完整分配。系统等权汇总所有意见，在大家的接受范围内寻找最接近综合意见的方案。范围无法同时满足时，明确展示参考结果与冲突量，由大家继续协商。工具提供协商建议，不保证策略诚实或全员满意。

支持总量 1–1,000,000 的整份资源，或 0.01–1,000,000 的小数资源。总量守恒，尾差同等条件按玩家顺序补齐。金币图标表达公平参与，实际分配按本局意见计算。

## 离线与隐私

下载 index.html 后，可以直接在浏览器打开。图片、样式和逻辑全部内嵌，发送这一个文件即可离线使用。

网页首次加载访问 GitHub Pages，随后全部计算在本机进行。站点托管访问日志由 GitHub 管理；姓名、期望与猜测仅保留在当前页面内存中，没有上传、账号、埋点或持久存储。

刷新、关闭或浏览器页面缓存恢复会清空本局。盲填遮挡覆盖正常页面操作；开发者工具仍可读取运行时内存，适合同桌、彼此信任的参与者。

## 开发

- 源码：src/；生成图原文件与无损 WebP：assets/。
- 构建：python3 build.py，Python 标准库即可。
- 算法测试：node --test qa/engine.test.cjs。
- 浏览器测试：安装 Playwright 和 Chrome，通过 PLAYWRIGHT_MODULE、CHROME_PATH 指定本地安装，然后执行 node qa/general-browser.test.cjs。
- 向 main 推送后，GitHub Actions 重建页面、验证提交产物与算法，再发布 GitHub Pages。
